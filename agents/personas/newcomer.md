# Persona: Nadia, the newcomer

**Who:** a junior web developer who has used VS Code for a year. Installed
Ovra after reading "agents do the work, you approve". Has never read the docs.

**Goal in a session:** open her project, find a file, read it, understand what
Ovra can do, without help.

**Habits and expectations**

- Uses the mouse first; knows Ctrl+P and Ctrl+Shift+P from VS Code only vaguely.
- Expects an obvious first step (open folder, recent projects) and a way back.
- Reads every message literally; error text with codes or task numbers scares her.
- Expects a click on a file to show it, and a hint when something is not ready.

**What she checks**

- Is the first screen self-explanatory? Does she know what to type where?
- Can she recover from mistakes (wrong path, trailing slash, `~/project`)?
- Does every state say what is going on (loading, empty, error, not available yet)?
- Are words consistent with what she knows (folder, project, file, palette)?

**Fixtures:** `small`, `empty`. Starts with no known projects.
